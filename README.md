# Ghost Nets Awareness Website

## Project Overview
This website explores the issue of ghost nets and abandoned fishing gear in marine environments. 
It aims to raise awareness about the environmental, ethical, and regulatory challenges surrounding ghost fishing.

## Website Pages
- Home – Introduction to ghost nets.
- Timelines – Historical development of ghost nets and fishing gear.
- Ethics – Ethical concerns surrounding ghost fishing.
- Regulations – International and EU regulations addressing ghost gear.
- News – Links to recent news and articles about ghost nets.
- References – All sources used across the website listed.
- Request Information – A form where users can request more information.

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Hidden Treasure Page
A hidden page exists within the website.

To access it, enter a URL containing three numbers separated by forward slashes.

Example:
http://localhost:8000/5/10/3/

## Running the Project
1. Clone the repository
2. Navigate to the project directory
3. Run:

python manage.py runserver

4. Open:

http://127.0.0.1:8000/
